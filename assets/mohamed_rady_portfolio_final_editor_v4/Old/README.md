# Mohamed Rady Portfolio — Final Editor

Based on the original first portfolio design.

## Page order
1. Hero / Banner — portrait background + editable headline and description
2. My Works
3. About Me
4. Contact Me

## Hero / Banner controls
Inside **Edit Site → Site Settings** you can:
- Upload/replace the background image
- Choose image position
- Choose cover / contain / stretch
- Change image opacity
- Change dark overlay
- Preview the background before saving

The default hero uses a portrait crop made from the portfolio's first page.

## Other controls
Everything from the previous editor remains:
- Edit all visible text
- Font family, size, weight, tracking, line height
- All colors
- Layout and spacing
- Work categories
- Add/manage image, video and PDF projects
- Backup / restore

This editor stores its settings locally in the browser. For an online multi-device CMS, connect the editor to cloud storage/database.
